# Ícones do WPE GUI

Ícones originais em SVG, com grade de 24 × 24, traço de 1,8 e cor clara `#e6e8ee` para o tema escuro. `app.svg` é o ícone principal vetorial de 512 × 512; a pasta `png/` contém suas versões rasterizadas.

Os nomes identificam a função: library, settings, search, refresh, folder, play, pause, stop, monitor, wallpaper, video, web, sliders, check, close, download, power e lock.

Em QML, use `icon.source: "../assets/icons/refresh.svg"` em um Button ou `source` em um Image. Os arquivos foram preparados sem alterar a interface atual.
